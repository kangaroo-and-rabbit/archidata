Archi-data Framework

Archi-data is a Java framework for building REST servers backed by MongoDB. It provides a complete stack for rapid API development: data access, authentication, validation, and client code generation.

Features

  • REST server with Jakarta JAX-RS (Grizzly/Jersey):
    • Role-based access control (JWT + API keys)
    • Built-in OpenAPI 3.0.3 specification generation
    • Normalized error responses
    • TypeScript / Python client generation
  • MongoDB data access layer:
    • Object introspection and automatic CRUD operations
    • Support for ObjectId, Long, and UUID primary keys
    • Soft delete, timestamps, and relationship management
    • Database migration engine
  • Model annotations (@Collection, @Field, @Id, @InitValue, relations, indexes) and Bean Validation
  • Cross-cutting services:
    • Transparent field encryption (AES-GCM, X25519, RSA)
    • Declarative MongoDB index management and query statistics
    • Incremental change journal and real-time change streams
    • Offset pagination through HTTP headers
  • Test utilities for integration testing

Quick start

A model is a plain class extending one of the base entities; the data access layer works by introspection, there is no mapping file:

{@code
@Collection("task")
public class Task extends OIDGenericDataSoftDelete {
	@NotNull
	@Size(max = 200)
	public String title;
	public Boolean completed = false;
}
}

Then use the static {@link org.atriasoft.archidata.dataAccess.DataAccess} facade (the database is configured with {@link org.atriasoft.archidata.tools.ConfigBaseVariable}):

{@code
ConfigBaseVariable.setBdDatabase("my_app");

final Task task = new Task();
task.title = "Write the javadoc";
final Task created = DataAccess.insert(task);

final Task loaded = DataAccess.getById(Task.class, created.getOid());
final List open = DataAccess.gets(Task.class,
		new Condition(Filters.eq("completed", false)),
		new Limit(10));
}

To expose it over REST, add a JAX-RS resource, register it with an {@link org.atriasoft.archidata.filter.AuthenticationFilter} subclass on a Jersey ResourceConfig, and secure each method with @RolesAllowed or @PermitAll. The full walk-through is in the first tutorial linked below.

Prerequisites

  • Java 25 (the project is compiled with source and target 25)
  • Maven 3.8+
  • MongoDB 6+ (replica set required for transactions and change streams)
